# My Task Manager — Docker жобасы

## 1. Жоба туралы

**My Task Manager** — тапсырмаларды басқаруға арналған интерактивті веб-қосымша. Жоба HTML, CSS және JavaScript технологиялары арқылы жасалған және Docker контейнерінде Nginx веб-сервері арқылы іске қосылады.

Жобаның негізгі мақсаты — Docker технологиясын пайдаланып, жеке веб-қосымшаны құру, контейнерге орналастыру және Docker Hub платформасына жүктеу.

## 2. Негізгі мүмкіндіктері

- Жаңа тапсырмалар қосу
- Тапсырмаларды орындалды деп белгілеу
- Қажет емес тапсырмаларды жою
- Орындалған тапсырмалар санын көрсету
- Тапсырмаларды браузерде автоматты сақтау
- Docker контейнерінде іске қосу

## 3. Қолданылған технологиялар

| Технология | Мақсаты |
|---|---|
| HTML5 | Веб-беттің құрылымын жасау |
| CSS3 | Сайттың дизайнын жасау |
| JavaScript | Интерактивті функцияларды орындау |
| LocalStorage | Тапсырмаларды браузерде сақтау |
| Docker | Қосымшаны контейнерге орналастыру |
| Nginx | Веб-сервер ретінде пайдалану |
| GitHub | Жобаның бастапқы кодын сақтау |
| Docker Hub | Docker образдарын сақтау |

## 4. Жобаның құрылымы

```text
my-custom-site/
│
├── index.html
├── Dockerfile
└── README.md
```

**index.html** — веб-сайттың интерфейсі мен JavaScript функциялары.

**Dockerfile** — Docker образын құруға арналған нұсқаулық.

**README.md** — жоба туралы ақпарат және оны іске қосу жолдары.

## 5. Docker арқылы іске қосу

### 5.1. Docker образын құру

```bash
docker build -t my-custom-site:v2 .
```

### 5.2. Контейнерді іске қосу

```bash
docker run -d --name custom-website -p 8081:80 my-custom-site:v2
```

### 5.3. Веб-сайтты ашу

Браузерге келесі мекенжайды енгізу:

http://localhost:8081

### 5.4. Контейнерлерді тексеру

```bash
docker ps
```

### 5.5. Контейнерді тоқтату

```bash
docker stop custom-website
```

## 6. Dockerfile

```dockerfile
FROM nginx:alpine

COPY index.html /usr/share/nginx/html/index.html

EXPOSE 80
```

**Түсіндірме:**

- `FROM nginx:alpine` — Nginx негізіндегі Docker образын пайдалану.
- `COPY` — HTML файлын контейнер ішіне көшіру.
- `EXPOSE 80` — веб-сервердің 80-портын көрсету.

## 7. Docker Hub платформасына жүктеу

Docker Hub аккаунтына кіру:

```bash
docker login
```

Docker образына жаңа атау беру:

```bash
docker tag my-custom-site:v2 YOUR_USERNAME/my-custom-site:v2
```

Docker Hub платформасына жүктеу:

```bash
docker push YOUR_USERNAME/my-custom-site:v2
```

`YOUR_USERNAME` орнына Docker Hub пайдаланушысының логині жазылады.

## 8. Мәліметтерді сақтау

Қосымшада тапсырмалар браузердің **LocalStorage** сақтау жүйесінде сақталады.

Сондықтан веб-бетті жаңартқан кезде тапсырмалар жоғалмайды. Мәліметтер серверде емес, пайдаланушының браузерінде сақталады.

## 9. Қорытынды

Бұл жобада Docker технологиясы арқылы жеке веб-қосымша жасалды.

Жұмыс барысында Dockerfile құрылды, Docker образы жинақталды және веб-сайт контейнер ішінде іске қосылды.

Сонымен қатар тапсырмаларды қосу, жою, орындалуын белгілеу және сақтау функциялары жүзеге асырылды.

Жоба Docker контейнерлерімен жұмыс істеу, веб-қосымшаларды орналастыру және Docker Hub платформасын қолдану дағдыларын дамытуға мүмкіндік береді.
